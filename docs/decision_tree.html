Invalid conditions — by branch
ATrain base model — never valid
  • kalman_noise 2D as the primary sweep axis
  • 4d_grid sweep
  • Nested LR sweep (online-learning concern only)
  • retrain_per_value=false — usually invalid unless init-comparison goal
BEvaluate fixed model — never valid
  • No checkpoint provided (hard block)
  • 4d_grid sweep
  • Nested LR sweep
  • Weight updates / gradient steps enabled
  • Retrain per sweep value (evaluation never trains)
COnline learning — never valid
  • No checkpoint provided (hard block)
  • Static-only data — trajectory stream required
  • kalman_noise 2D as top-level sweep (belongs under B)
  • LR nested sweep when sweep axis ≠ eta
  • Base model training during OL run
DFull pipeline — never valid
  • Start from checkpoint-only with train=false (that is B or C, not D)
  • Parameter sweep at the pipeline level (sweeps belong on individual branches)
  • 4d_grid or kalman_noise 2D as full-pipeline mode
  • Sweep inside stage 2 or stage 3
