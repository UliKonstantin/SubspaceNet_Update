Terminology (locked for T1–T3, T5–T7)

Every reported number is a loss metric of an algorithm’s θ at a time, in deg or rad. Early/late bands are debug only — not performance.

T1 = additive position-η (x = nd + δ). T1.2 = additive SV-noise. T1.3 = index-scaled pitch-η / eq. 20 (x = n(d+δ)). T2/T3 = same formula, η P5-matched per SNR / M (target ~11° before-adapt). T4 dropped — those three already cover the mismatch modes (no separate magnitude-only / phase-only test).

Detector — T1–T3 published cells fire with CUSUM + abs on unsupervised adaptation_loss. T6 mixed locked the protocol (40 TP / 0 FN / 0 FP / 10 TN). glrt_z archives are not overwritten. See tab Detector — CUSUM+L.

T7 = qualitative MUSIC P(θ) on SN Rz (ESPRIT ckpt, MUSIC head only for the figure). 1-traj smoke on T1 N=9 CUSUM. Tab T7 — MUSIC P(θ).

Time of measurement

NameDefinition
pre-drift Mean error over the 5 windows immediately before the drift window (η jump). T1 drift is w40 → windows 35–39.
post-drift Mean error over the last 20 windows of the run. If last_window − drift_window < 20, use only windows after adaptation ends (post-adaptation), not a padded 20.
early / late Debug only (old w45–55 / w80–120). Not a performance number. Do not report as a paper result.

Loss metric

NameDefinition
RMSPERoot-mean-square periodic error vs GT. Performance metric. Config: supervised_rmspe.
MSIERMSPE(EKF θ, net θ). No GT. Unsupervised train / GLRT signal. Config: unsupervised_rmspe.
BCEBinary cross-entropy on a DOA grid (DeepCNN distillation). Parked with DeepCNN. Not a T1–T3 SN number.
