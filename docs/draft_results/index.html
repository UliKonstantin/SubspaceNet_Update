T1 — Antenna count sweep (SubspaceNet) smoke ds=3

Online learning under calibrated-model mismatch (η jump to 0.9 @ w40) while sweeping array size N ∈ {6, 9, 12, 18}. M=3, SNR=10 dB, stride=1, 3 trajectories × 200 windows.

Findings

  • N=9: strongest win — ours 0.029→0.024 vs no_adapt 0.093→0.131 post-η.
  • N=6: ours 0.076→0.063 vs no_adapt 0.067→0.104.
  • N=18 @ η=0.9: no_adapt 0.067→0.046 already good; ours slightly worse (0.051→0.049).
  • Genie handoff fix at drift latch improved supervised genie on all N.
  • Adaptive LR: dG0=14.5 pinned LR to ~5e-4; retuned dG0=7.5 → LR 0.004–0.02 (verified N=9).
  • DeepCNN 3-traj N=9: online hurts (0.143→0.164 vs no_adapt 0.039→0.057) — needs fix before paper arm.
