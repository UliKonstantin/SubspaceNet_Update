Online learning under calibration drift @ w40, N ∈ {6, 9, 12, 18}. Current protocol: spacing-scale jump 1.0→1.03 (T1_spacing_scale_smoke). Legacy position-η runs kept under T1_final_recipe.

Calibration drift — why spacing scale (Option B)

Position η — random per-sensor offsets δn∈[−ηλ,+ηλ]. Differential, ~zero-mean → subspace averaging + EKF smoothing made N=12/18 look like “self-heal” (no sustained supervised hit even at η=5).

Spacing scale ε — global d′=(1+ε)d on every element. Coherent manifold warp → DOA bias that does not average out with N. Same ε stresses all apertures comparably; snapshots regenerated after w40 for eval, no-adapt, unsupervised, and genie arms.

  • drift_type: spacing_scale, spacing_scale_increment: 0.03, jump @ w40, η disabled (0).
  • Pipeline: SystemModelParams.spacing_scale → steering positions → snapshot synthesis → SubspaceNet → EKF (all arms share one generator).

Findings (legacy position η — T1_final_recipe)

  • N=9: strongest win under η=0.9 — largest adaptation margin.
  • N=12/18: flat/negative Δlate under position η — low-sensitivity regime (motivated spacing-scale switch).
  • Adaptive LR vs N: LR driven by unsupervised GLRT dG, not N directly — N=9 often pinned to floor.

Findings (spacing-scale — T1_spacing_scale_smoke)

  • Single jump 1.0→1.03 @ w40 (max_spacing_scale=1.03 blocks repeat @ w80).
  • Early post-drift (w45–55) Δ vs pre: N=9 +1.1°, N=12 +1.1°, N=18 +0.9°, N=6 flat — large-N matched stress (fixes position-η self-heal).
  • Late (w80–120) still trends down on no-adapt (trajectory/EKF segment); use early band for matched degradation.
  • Verify: python3 scripts/verify_T1_spacing_scale_smoke.py

Adaptive LR — drift magnitude, not antenna count (but N couples in via loss)

Formula: dG = G_t − baseline_mean on the unsupervised adaptation-loss GLRT series, then sigmoid(dG; dG0=7.5) → LR. N is not an input.

T1_final_recipe (3 traj × 4 N), mean dG at z-trigger:

  • N=6: dG≈7.7 → LR 1e-3–1.7e-2
  • N=9: dG≈3.0 → LR 5.5e-4 (floor) — training-N model: η jump produces smaller unsupervised loss changepoint
  • N=12: dG≈6.0 → LR 5e-4–9e-3
  • N=18: dG≈8.9 → LR 1e-3–1.9e-2

So N-dependent LR is a proxy artifact: array/model mismatch changes the adaptation-loss GLRT amplitude, not η alone. Fix options: map LR from z-score or reference-metric GLRT; normalize dG by baseline_std; or use η-calibrated drift signal only.
